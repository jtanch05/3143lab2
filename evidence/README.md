# CAAS evidence

These files are supplementary evidence for the FIT3143 Lab 2 submission.

- `screenshots/` contains the available screenshots of correctness checks and CAAS job submission.
- `prime_outputs/` contains sorted prime lists from representative n = 100,000,000 Task 1 and Task 2 runs.
- `caas_logs/` contains the available run reports, comparison outputs, dataset reports, and Slurm logs.

Only include evidence for jobs that were actually run. Review the screenshots and logs before submitting, and add any newer CAAS screenshots or job output required by your final presentation.
